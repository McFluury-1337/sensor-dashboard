# BRIEF: Этап 6 — хостинг
Дата: 2026-09-22

## Формулировка своими словами
Этот этап распадается на две принципиально разные части.

**Часть A — код (делаю сам, в репозитории).** `db.py` учится работать с двумя бэкендами: SQLite (как сейчас, локально) и MySQL (на хостинге) — выбор через `.env` (`DB_BACKEND`), без изменений в вызывающем коде (`app.py`, `simulator.py`). Плюс `passenger_wsgi.py` — точка входа, которую ищет Beget. Плюс новые переменные окружения для подключения к MySQL.

**Часть B — сам хостинг (делаете вы, я не могу и не буду).** Регистрация аккаунта на Beget, выбор тарифа, создание сайта/поддомена, создание базы MySQL в панели, включение HTTPS через Let's Encrypt, выкладка кода на сервер, настройка `.env` на сервере, cron для симулятора. Это создание аккаунта и (возможно) платёж — такие действия я не выполняю ни при каких обстоятельствах, и у меня физически нет доступа к вашей будущей панели Beget. Я подготовлю пошаговый ранбук и буду разбирать с вами ошибки, если пришлёте логи/скриншоты, но не выполняю эти шаги за вас.

## Контекст
- Стек с самого начала предполагал этот переезд: «у себя SQLite, на хостинге MySQL, все обращения к базе через один модуль» — записано ещё на Этапе 0/1, реализуется сейчас.
- Локально MySQL/Docker не было — поставил MariaDB через Homebrew только для тестов (не для продакшена), чтобы реально прогнать SQL, а не просто написать «по памяти».
- Драйвер — PyMySQL (ваш выбор доверен мне, я рекомендовал его: чистый Python, не требует компилятора — важно на shared-хостинге, где часто нет прав на сборку C-расширений).
- Аккаунта на Beget пока нет (ваш ответ) — ранбук начинается с регистрации.
- Про точный экран «тип сайта → Python/Passenger» в актуальной панели Beget я не нашёл однозначного публичного описания (поиск по их базе знаний и Google не дали прямого попадания) — в ранбуке отмечу это как шаг, который надо свериться с их актуальной панелью или тикетом в поддержку, а не выдумывать названия кнопок.

## Критерии успеха
Часть A (проверяю сам, сейчас):
- [ ] `db.py` работает с MySQL (реально протестировано против локальной MariaDB, не только «должно работать»)
- [ ] Тот же `db.py` продолжает работать с SQLite — все 31 существующих тестов зелёные без изменений
- [ ] `passenger_wsgi.py` — рабочая точка входа для Passenger (`from app import app as application`)
- [ ] `.env.example` содержит все переменные, нужные для MySQL-режима
- [ ] Новая зависимость (`pymysql`) в `requirements.txt`, обоснована в `DECISIONS.md`

Часть B (проверяете вы, по ранбуку, после этого разговора):
- [ ] Аккаунт на Beget, сайт/поддомен привязан
- [ ] MySQL база создана в панели, `.env` на сервере заполнен

- [ ] HTTPS включён (Let's Encrypt в панели)
- [ ] Симулятор запускается по cron раз в несколько минут
