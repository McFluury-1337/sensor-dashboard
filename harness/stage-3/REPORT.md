# REPORT: Этап 3 — API и настоящий симулятор
Дата: 2026-09-21

## Что сделано
- `db.py` — рефакторинг `path=DB_PATH` → `path=None` + подстановка `DB_PATH` внутри тела функции, чтобы тесты могли подменить БД через `monkeypatch.setattr(db, "DB_PATH", ...)` (со старым кодом это не сработало бы — Python фиксирует значение аргумента по умолчанию в момент объявления функции, а не вызова).
- `config.py` — минимальный загрузчик `.env` на стандартной библиотеке, без внешних зависимостей.
- `.env` (реальный ключ, в `.gitignore`) и `.env.example` (плейсхолдер, в репозитории).
- `app.py` — `POST /api/readings` (проверка ключа через `hmac.compare_digest`, проверка типов и знака трёх полей, серверный timestamp, запись через `db.py`, ответы 201/400/401) и `GET /api/readings?limit=N` (без проверки ключа).
- `simulator.py` — переписан: не импортирует `db`, генерирует показание как раньше, отправляет `POST` через `urllib.request` с заголовком `X-API-Key`; при HTTP-ошибке печатает код и тело ответа вместо traceback.
- `tests/conftest.py` — фикстура `client`: временный SQLite-файл на каждый тест, monkeypatch `db.DB_PATH` и `app.API_KEY`, удаление файла после теста.
- `tests/test_api.py` — 7 тестов через `app.test_client()`.
- `harness/PROJECT.md`, `DECISIONS.md` обновлены.
